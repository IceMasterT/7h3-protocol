Your agent stack has a security gap — here's where.

The gap

What existing protocols miss

📡
MCP — unsigned JSON-RPC

Every tool call sent in the clear. No signature, no freshness guarantee. Traffic is trivially replayable.

🪪
A2A — signs the identity card, not the traffic

Authentication at connection time. Individual messages remain unsigned and replayable mid-session.

🔁
No replay protection by default

Captured messages can be reinjected. Duplicate execution = silent data corruption or double-spend.

✦ AIP Solution

What @7h3/protocol adds

✍️
Per-message signing

Every envelope: HMAC-SHA256 or Ed25519 over deterministic canonical form. Tamper is detectable in transit.

🛡️
Replay cache (Redis, atomic)

SET NX PX per (sender, messageId, nonce). Fleet-wide — revoke a key on one node, rejected everywhere.

📦
Drop-in MCP wrapper

Wrap your existing handler: wrapMcpServer(handler). Four threat bindings enforced. Zero handler changes.
