4 threat bindings. One drop-in wrapper.

Wrap your MCP server. Four attack vectors closed. Zero handler changes.

🎯
Recipient
Blocks → cross-server replay
Envelope is bound to a specific recipient. A captured message cannot be relayed to a different server and accepted.
🕵️
Sender
Blocks → response spoofing
Response must be signed by the same identity that received the request. Forged responses from rogue nodes are rejected.
🔗
Correlation
Blocks → response substitution
Response carries the request's correlationId. Swapping a legitimate response with a forged one is detectable.
⏱️
Replay
Blocks → duplicate execution
Redis-atomic SET NX PX per (sender, messageId, nonce). On by default. Fleet-wide when Redis is wired.
